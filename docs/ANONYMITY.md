# Anonymous artifact scope

This directory is assembled from an explicit allowlist of scientific data,
source modules and configurations. It contains no Git history or remote URL,
personal name/contact metadata, institution-specific API deployment address,
private credential file, account-specific scheduler script, host logs, model
response journal, scored model output or cached environment.

Dataset text is preserved, including its fictional entities and person names.
Public model identifiers and checkpoint hashes describe measurement conditions
and are retained. They are not author identifiers. Compression headers omit
source filenames and modification timestamps. Archive entries use relative paths
and neutral timestamps, without symlinks or Unix user/group ownership metadata.

Validation checks known private identifiers and generic credential/contact/path
patterns across filenames and decompressed contents. A clean automated scan is
evidence about the packaged bytes, not a guarantee against identification through
the research topic or outside information. Publish only this artifact directory,
not its parent workspace or private release-building scripts. Use an anonymous
hosting account and avoid identifying commit authors when preparing review access.
